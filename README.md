# TrafficTunes 🚦🎵

TrafficTunes is a smart city–based project that transforms traffic noise into musical melodies. It uses Google AI concepts to analyze traffic sound patterns and represent congestion through xylophone-style music.

## Problem Statement
Traffic congestion causes stress and noise pollution. Existing systems display traffic data but lack engaging and creative representation.

## Solution
TrafficTunes converts traffic honks into music. Higher congestion results in faster and higher-pitched melodies, allowing users to understand traffic conditions through sound.

## Features
- Traffic audio upload
- Traffic level detection (Low / Medium / High)
- Xylophone melody generation
- Simple visual dashboard

## Google Technologies Used
- Google Cloud Platform
- Firebase

## Google AI Tools Integrated
- Google Speech-to-Text API

Functional Prototype
